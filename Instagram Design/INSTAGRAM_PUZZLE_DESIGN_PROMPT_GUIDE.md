## 1. المعادلة الهندسية والمقاسات القياسية

> **القاعدة الذهبية:** إنستغرام يقبل الصور الفردية بأفضل دقة بنسبة **4:5 (Portrait)** بمقاس **1080 × 1350 بكسل**.  
> لذلك تُبنى اللوحة الرئيسية (Master Canvas) بمضاعفات هذا الرقم بدقة صفرية:

| نوع الشبكة | عدد البوستات | أبعاد اللوحة الرئيسية (Master Canvas) | أبعاد كل بوست بعد التقطيع |
| :--- | :---: | :---: | :---: |
| **صف واحد (3 بوستات)** | 3 | **3240 × 1350 px** | 1080 × 1350 px |
| **صفين (6 بوستات)** | 6 | **3240 × 2700 px** | 1080 × 1350 px |
| **3 صفوف (9 بوستات)** | 9 | **3240 × 4050 px** | 1080 × 1350 px |

## 2. قاعدة المماس الأفقي لمنع انكسار الخط
### (The Zero-Slope Horizontal Tangent Rule)

> [!IMPORTANT]
> **لماذا كان ينكسر الخط أو يظهر في الصورة الوسطى مرتفعاً؟**  
> عند عبور خط مائل فوق الفاصل الأبيض للإنستغرام (1px إلى 3px)، يختفي جزء من الميلان داخل الفاصل مما يسبب قفزة رأسية بصرية (Step Discontinuity). كما أن التقريب الكسري لشاشات الهواتف (Sub-pixel Rounding) يزيد هذا الانزياح.

### 🛡️ الحل الهندسي المعتمد:
1. عند خطوط القص العمودية (`x = 1080` و `x = 2160`):
   * يجب أن تكون زاوية ميلان الخط **أفقية تماماً مستوية (Slope `dy/dx = 0`)**.
   * يجب تثبيت الارتفاع `Y` لنفس القيمة (مثلاً `Y = 480`) لمسافة لا تقل عن **40 بكسل** قبل وبعد خط الفاصل.
2. عدم وضع قمة القوس (Apex) بارتفاع حاد داخل الصورة الوسطى وحدها؛ بل جعل التموج انسيابياً وهادئاً (بفارق لا يتجاوز 40-50 بكسل فقط).

## 3. مناطق الأمان للقص المربع (Safe Zones)

عند عرض حساب الإنستغرام، يظهر البوست في البروفايل كمربع **1:1 (1080 × 1080 px)** مقتطعاً من منتصف البوست الطولي **4:5 (1080 × 1350 px)**.

```
+-----------------------------------------------------------+  y = 0
|        منطقة الهدر العلوية (Top Buffer: 135 px)            |  تُقص في البروفايل المربع
+===========================================================+  y = 135
|                                                           |
|                 المربع الآمن (Safe Square)                |
|                    1080 × 1080 px                         |  يظهر كاملاً في البروفايل
|          (توضع هنا كل النصوص والبطاقات والشعارات)         |  وفي المعاينة الطولية
|                                                           |
+===========================================================+  y = 1215
|        منطقة الهدر السفلية (Bottom Buffer: 135 px)         |  تُقص في البروفايل المربع
+-----------------------------------------------------------+  y = 1350
```

* **الهوامش الجانبية عن خطوط القص:** يجب إبعاد النصوص والبطاقات مسافة **100 بكسل** عن الحواف اليمنى واليسرى للبوست لضمان عدم ملامسة خط القطع.

## 4. ترتيب النشر الزمني على إنستغرام (Publishing Order)

> [!CAUTION]
> إنستغرام يدفع المنشورات الجديدة إلى اليمين واليسار من الأسفل للأعلى (Reverse Chronological Order).  
> **إذا نُشرت الصور بالترتيب الخاطئ فستنعكس الشبكة بالكامل!**

### لشبكة الـ 3 بوستات (صف واحد):
1. **الخطوة 1 (يُنشر أولاً):** البوست الأيمن (`Post 1 - Right: x = 2160 to 3240`).
2. **الخطوة 2 (يُنشر ثانياً):** البوست الأوسط (`Post 2 - Center: x = 1080 to 2160`).
3. **الخطوة 3 (يُنشر ثالثاً):** البوست الأيسر (`Post 3 - Left: x = 0 to 1080`).

### لشبكة الـ 6 بوستات (صفين):
* أولاً: نشر **الصف السفلي (Row 2)** بالكامل:
  1. بوست يمين أسفل.
  2. بوست وسط أسفل.
  3. بوست يسار أسفل.
* ثانياً: نشر **الصف العلوي (Row 1)** بالكامل:
  4. بوست يمين أعلى.
  5. بوست وسط أعلى.
  6. بوست يسار أعلى.

## 6. كود ومعادلة المنحنى الرياضي المتصل (SVG Bezier Path)

لإنشاء خط ليزري متصل يمر عبر البوستات الثلاثة مع تطبيق **المماس الأفقي المستوي بدقة صفرية**:

```xml
<svg viewBox="0 0 3240 1350" fill="none" xmlns="http://www.w3.org/2000/svg">
  <defs>
    <!-- تدرج لوني زمردي فخم -->
    <linearGradient id="ribbonGrad" x1="0%" y1="50%" x2="100%" y2="50%">
      <stop offset="0%" stop-color="#10b981" stop-opacity="0.85" />
      <stop offset="30%" stop-color="#34d399" stop-opacity="0.95" />
      <stop offset="50%" stop-color="#06b6d4" stop-opacity="1.0" />
      <stop offset="70%" stop-color="#34d399" stop-opacity="0.95" />
      <stop offset="100%" stop-color="#10b981" stop-opacity="0.85" />
    </linearGradient>

    <!-- توهج ناعم -->
    <filter id="laserGlow" x="-20%" y="-20%" width="140%" height="140%">
      <feGaussianBlur stdDeviation="12" result="blur" />
      <feMerge>
        <feMergeNode in="blur" />
        <feMergeNode in="SourceGraphic" />
      </feMerge>
    </filter>
  </defs>

  <!-- المسار الرئيسي المضمون هندسياً:
       - نقطة عبور الفاصل الأول: x = 1080, y = 480 (زاوية أفقية dy/dx = 0)
       - نقطة عبور الفاصل الثاني: x = 2160, y = 480 (زاوية أفقية dy/dx = 0)
       - قمة المنحنى في الوسط: x = 1620, y = 440 (ارتفاع طفيف هادئ 40px فقط)
  -->
  <!-- خط التوهج المحيطي -->
  <path d="M 180 720 C 480 720, 780 480, 1080 480 C 1320 480, 1480 440, 1620 440 C 1760 440, 1920 480, 2160 480 C 2460 480, 2760 720, 3060 720"
        stroke="url(#ribbonGrad)" stroke-width="46" fill="none" opacity="0.32" filter="url(#laserGlow)" />

  <!-- خط الليزر الأساسي الصريح -->
  <path d="M 180 720 C 480 720, 780 480, 1080 480 C 1320 480, 1480 440, 1620 440 C 1760 440, 1920 480, 2160 480 C 2460 480, 2760 720, 3060 720"
        stroke="url(#ribbonGrad)" stroke-width="7" fill="none" filter="url(#laserGlow)" />

  <!-- قلب الليزر الأبيض المشع -->
  <path d="M 180 720 C 480 720, 780 480, 1080 480 C 1320 480, 1480 440, 1620 440 C 1760 440, 1920 480, 2160 480 C 2460 480, 2760 720, 3060 720"
        stroke="#ffffff" stroke-width="2.4" fill="none" opacity="0.95" />
</svg>
```

## 7. نظام الهوية والألوان والخطوط (Brand System)

### ألوان الهوية:
* **الأخضر الزمردي الأساسي (Neon Emerald):** `#10b981` (يمثل التقنية والذكاء الاصطناعي والحداثة).
* **الأخضر المؤسسي العميق (Deep Emerald):** `#059669` / `#047857` (للعناوين والنصوص البارزة).
* **السيان السيبراني (Cyan Accent):** `#06b6d4` (للتدرجات ونقاط التوهج).
* **الخلفية الداكنة الفاخرة (Deep Navy/Slate):** `#0b1120` مع `#0f172a` (بديل أنيق للأسود الصامت).
* **الخلفية الفاتحة الحديثة (Clean Platinum):** `#f8fafc` مع لمسات زجاج بلوري `rgba(255,255,255,0.95)`.

### الخطوط المعتمدة:
* **العناوين العربية:** خط `Cairo` بأوزان `900 (Black)` و `800 (ExtraBold)`.
* **العناوين والرموز الإنجليزية:** خط `Plus Jakarta Sans` بأوزان `800 (ExtraBold)` و `700 (Bold)`.
